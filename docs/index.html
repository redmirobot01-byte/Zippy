🛠️ VPN-dan soň brauzer / internet işlemeýän bolsa

  • Proxy galyndysy (köplenç sebäp şu): Win + R → inetcpl.cpl → Connections → LAN settings → «Use a proxy server for your LAN» tikini aýyryň → OK. Soňra Chrome-y doly ýapyp täzeden açyň.
  • TUN galyndysy: Win + R → ncpa.cpl → «Happ» / «wintun» atly adapteri tapyp, sag düwme → Disable; ýa-da Device Manager → Network adapters bölüminden aýyryň.
  • Tory arassalamak: Administrator hökmünde CMD açyň we netsh winsock reset, ipconfig /flushdns ýerine ýetiriň, soňra kompýuteri täzeden açyň.
  • Chrome-y dikeltmek: chrome://settings/reset → «Restore settings to their original defaults»; chrome://extensions bölüminde nätanyş goşundylary öçüriň.
  • Ýükleme işlemeýän bolsa: şol bir salgyny Microsoft Edge-den açyp görüň (ol Windows-da öňünden bar) ýa-da telefonyňyzyň internet paýlaşmasyny (hotspot) ulanyň.
  • Ähli brauzer birwagtda işlemeýär, Wi-Fi bolsa işleýär? Bu Windows-yň ulgam proksisi / DNS-i ýa-da galan VPN adapteri — brauzerleriň ählisi şol bir ulgam sazlamasyny ulanýar. Aşakdaky awtomatik bejergi faýlyny Administrator hökmünde işlediň.
